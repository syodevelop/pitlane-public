# Security reports

Contact the project through the official [@playpitlane account on X](https://x.com/playpitlane). Ask for a private reporting channel before sharing exploit details. Do not post credentials, player data or an exploitable vulnerability in a public issue.

Use a local installation to reproduce issues. Do not test against other players, extract application records or attempt to access the production admin.

This source release has automated tests but has not received an independent security audit. The current workshop saves client-simulated game statistics. They must not be treated as verified balances for token payouts.
