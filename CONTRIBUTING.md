# Contributing

Use issues for reproducible bugs and specific suggestions. Include the browser, viewport size, steps to reproduce and expected behavior. Remove wallet details and personal information from screenshots and logs where they are not needed.

For code changes, use Node.js 24, follow the existing TypeScript and CSS conventions, and run `npm run verify`. Keep changes focused. Check both desktop and touch input when changing gameplay or layout.

Use [TESTING.md](TESTING.md) for the supported commands, manual release checklist and the information to include in a test report.

Discuss changes to progression, permanent character selection, wallet authentication or storage before changing their behavior. Add meaningful tests for account isolation, save conflicts or progression rules you modify.

Never include credentials, player records, wallet keys or database exports in an issue or pull request. Contact the project through [@playpitlane](https://x.com/playpitlane) for sensitive reports. See [SECURITY.md](SECURITY.md).

The repository is published for source review. Check [LICENSE](LICENSE) before redistributing code or assets. A submitted pull request does not change the project's licensing terms.
